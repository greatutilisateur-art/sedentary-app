## 1. Accueil — activité récente disponible

```text
┌──────────────────────────────────────┐
│ Mes pauses                      ⚙    │
│                                      │
│ Prochaine proposition                │
│ vers 15 h 10                         │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ Dernière activité proposée       │ │
│ │ Une petite marche ?              │ │
│ └──────────────────────────────────┘ │
│                                      │
│ [             Suspendre            ] │
│                                      │
│ Modifier mes réglages                │
└──────────────────────────────────────┘
```

La carte `Dernière activité proposée` ouvre la consigne. Elle n'est pas une todo.

## 5. Écran activité

```text
┌──────────────────────────────────────┐
│                                      │
│ 2 à 5 min                            │
│ Debout nécessaire                    │
│                                      │
│ Une petite marche ?                  │
│                                      │
│ Lève-toi et marche tranquillement    │
│ quelques minutes.                    │
│                                      │
│          Autre activité              │
│                                      │
│          Pas maintenant              │
│                                      │
└──────────────────────────────────────┘
```

Aucun bouton fermer spécifique. Retour Android revient à l'accueil.

L'écran reste visible jusqu'à navigation. Aucune action de confirmation n'est requise.
