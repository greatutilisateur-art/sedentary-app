# UXWireframes_v1.1

Wireframes fonctionnels, sans choix graphique définitif.

## 1. Accueil

```text
┌──────────────────────────────────────┐
│ Mes pauses                      ⚙    │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ Prochaine proposition            │ │
│ │ vers 15 h 10                     │ │
│ └──────────────────────────────────┘ │
│                                      │
│ [ Suspendre jusqu'au prochain jour ]
│ Mettre en pause jusqu'à nouvel ordre         │
│                                      │
│ Tes créneaux                         │
│   10 h 10                            │
│   11 h 50                            │
│ → 15 h 10                            │
│   17 h 30                            │
│                                      │
│ Modifier mes horaires                │
└──────────────────────────────────────┘
```

## 2. Notification

```text
┌──────────────────────────────────────┐
│ Une petite marche ?                  │
│ 2 à 5 min · Touche pour voir         │
│                                      │
│ [Dans 10 min] [Dans 30 min]          │
│ [Pas maintenant]                     │
└──────────────────────────────────────┘
```

L'ordre réel des boutons peut dépendre des contraintes Android. Les reports ne sont affichés que lorsqu'ils restent valides ; `Pas maintenant` reste toujours disponible.
